Deflectometry Pattern Viewer

BẮT BUỘC trước khi chạy (Galaxy S23):

  • Brightness MAX kéo cao nhất, TẮT Adaptive brightness
  • TẮT Eye comfort shield (Settings → Display)
  • TẮT Dark mode, TẮT Always-On Display
  • TẮT Auto-rotate sau khi xoay landscape
  • Screen timeout ≥ 10 phút, bật Do not disturb

Vì sao quan trọng:

AMOLED dùng PWM dimming ở brightness thấp → cường độ flicker, phá phase shifting. Brightness MAX thì PWM tắt hoặc lên tần số rất cao. Eye Comfort Shield + Dark mode đổi gamma → mỗi ảnh có cường độ khác nhau.

Điều khiển:

  • Tap màn hình → pattern tiếp theo (8 patterns: V0–V3, H0–H3)
  • Chỉnh chu kỳ sọc bên dưới rồi START
